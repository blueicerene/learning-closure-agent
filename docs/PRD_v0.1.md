# PRD v0.1

## User

Rene, an AI-heavy goal-driven learner using ChatGPT, NotebookLM, PDF materials, transcripts, and web research.

## Core Job

At the end of a learning session, capture the current context and generate a useful closure that can be saved to Obsidian.

## Must Have

- Chrome Extension MV3 popup
- Capture current page
- Capture selected text
- Manual paste
- Local Express backend
- Mock `/api/closure` flow
- Optional real LLM mode
- Markdown save
- `learning-log.json`
- Last next action display

## Success Criteria

- Capture to saved Markdown takes 30 seconds or less in normal use.
- The user is willing to use it at least 5 times per week for two weeks.
- At least 3 future sessions start from a previous next action.
