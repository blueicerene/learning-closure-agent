# 法律英语复习小程序 V2 结项说明

结项日期：2026-07-31
版本：2.0.0
发布分支：`v0.2-learning-standard`

## 产品结果

V2 将原有学习收尾工具扩展为一个本地优先的法律英语学习工作台。核心闭环已经形成：

1. 在网页、Chrome PDF、输入框或截图中查词。
2. 获得中英文释义、音标、法律语境和例句。
3. 查到的词自动进入本地待学习池。
4. 系统生成容量受控且当天冻结的复习计划。
5. 用户通过四选一完成测试；答错进入强化，答对推进间隔。
6. 日历、每日提醒和桌宠提供持续但克制的学习反馈。

## V2 已纳入基线

- **法律词典**：在线检索与 AI 法律语境补全；失败时明确降级，不伪造结果。
- **查词入口**：网页选词浮层、Chrome PDF 单一右键查词、手动输入、图片 OCR、大王拖图。
- **自动收词**：用户主动查词后自动保存；重复查询计数去重并作为内部重要度信号。
- **Daily Plan v2**：校准期每日最多 20 题、待进入计划词最多 10 个、到期复习优先、当天开始后冻结、返回后从下一题继续。
- **测试反馈**：四个英文释义选项；结果页不论对错均可点击发音，并显示法律语境和例句。
- **重点强化**：首次答错稍后再检索；再错进入重点队列；题目质量问题不归因于用户记忆。
- **完成记录**：最近 7 天和整月日历；完整完成与未完整完成使用用户确认的大王真实照片标记。
- **词库治理**：待确认词暂停出题；支持编辑、重新查询、确认无误与安全移出；长正文片段不会被误当词条。
- **每日提醒**：Mac 端每天 20:00 在计划未完成时提醒一次，完成后停止。
- **桌宠大王**：透明置顶窗口、位置拖动、图片拖放、学习状态反馈、侧卧待机、悬停与左右拖动动作。
- **兼容能力**：原有学习会话收尾、Markdown、taxonomy、Learning Standard 和 progress API 保留。

## 已验收事实

- 用户已确认查词和测试功能可用。
- 用户已确认每日提醒可用。
- 用户已确认词库阶段验收通过。
- 用户已确认当前大王自然动作可作为 V2 基线。
- 真实词库、冻结计划和错误词条修复均按备份、保护哈希和授权写入流程执行。

## 数据与隐私

以下内容只保留在本机，不进入 GitHub：

- `output/` 中的真实词库、学习记录和备份。
- `server/.env` 与任何 API Key。
- `artifacts/` 中的真实路径截图、验收证据和临时素材。
- `.runtime-bin/`、构建产物、依赖缓存和 Python 缓存。

仓库只包含源代码、可复现测试、发布合同和运行必需的桌宠动画帧。

## 结项门禁

```bash
npm run build
npm run release:gate
npm run audit:decisions
npm run test:pet
git diff --check
```

发布前必须确认 `output/`、`.env`、`artifacts/`、缓存与密钥没有进入暂存区。

## 已知限制与后续边界

- iPhone 上的 iCloud 提醒同步与零重复事项尚缺单独设备验收；V2 只确认 Mac 每日提醒。
- 首个 7 天校准期保持 20/10 安全阀；后续只能基于真实耗时提出建议，不能自动改额度。
- 大王动画仍是 2.5D 帧动画，不是三维骨骼或逐根毛发模拟；V2 以当前用户接受的自然度收口。
- 本项目不得处理用户无权处理或明确禁止输入生成式 AI 的受限考试材料。

## 后续开发原则

V2 之后的改动单独建迭代合同，先保护以下基线：查词不超过一次明确点击、拖图自动完成 OCR 与查询、当天计划不被新增词扩张、真实学习数据不被测试修改、词库质量问题不算用户答错、提醒不重复、桌宠透明拖放不回归。
